# Task Manager – Full-Stack Task Management

Full-stack task manager with JWT auth, labels, due dates and filtering.
Built with React + TypeScript, Node.js + Express, PostgreSQL, Docker and GitHub Actions.

## Tech Stack
- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express, Prisma
- **Database:** PostgreSQL
- **Testing:** Jest, Supertest, React Testing Library
- **DevOps:** Docker, GitHub Actions
